# golem-notes-examples

Examples from [Golem Notes](https://golemnotes.substack.com), a series on
running a real agentic dev setup.

Each folder matches one part of the series. Everything here is a sanitized,
standalone version of my private setup: adapt paths, hostnames and model IDs
to your own.

| Part | Folder | Post |
|---|---|---|
| 1 | 01-the-map | [I talk to one agent. It runs the others.](https://golemnotes.substack.com/p/i-talk-to-one-agent-it-runs-the-others?utm_source=github&utm_medium=referral&utm_campaign=agentic-setup-01) |
| 2 | 02-remote-agents | [Close the laptop, the agent keeps working](https://golemnotes.substack.com/p/close-the-laptop-the-agent-keeps?utm_source=github&utm_medium=referral&utm_campaign=agentic-setup-02) |
| 3 | 03-mobile-relay | [My agents on two laptops, controlled from one phone app](https://golemnotes.substack.com/p/my-agents-on-two-laptops-one-phone-app?utm_source=github&utm_medium=referral&utm_campaign=agentic-setup-03) |
| 4 | 04-pr-review | [Every PR gets an agent review before a human sees it](https://golemnotes.substack.com/p/every-pr-gets-an-agent-review?utm_source=github&utm_medium=referral&utm_campaign=agentic-setup-04) |
